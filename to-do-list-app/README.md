# To-Do List Application

## Overview
This is a simple To-Do List application that allows users to add, remove, and manage their tasks efficiently. The application is built using HTML, CSS, and JavaScript.

## Project Structure
```
to-do-list-app
├── src
│   ├── index.html        # Main HTML document
│   ├── styles
│   │   └── style.css     # Styles for the application
│   └── scripts
│       └── app.js        # JavaScript functionality
├── package.json          # npm configuration file
└── README.md             # Project documentation
```

## Getting Started

### Prerequisites
- Node.js and npm installed on your machine.

### Installation
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd to-do-list-app
   ```
3. Install the dependencies:
   ```
   npm install
   ```

### Usage
1. Open `src/index.html` in your web browser to view the application.
2. Use the input field to add new tasks.
3. Click on the task to remove it from the list.
